# Aishwarya Dental Clinic and Implant Centre — website (ADC)

Public website for Aishwarya Dental Clinic and Implant Centre, Vidyanagar, Guntur, on ClinicFlow247 Enterprise (white label). Built from the SPDC site pattern: all content in `/content` (zod-validated, approved/placeholder status), live ClinicFlow booking with honest fallbacks, and a generated tenant file `tenant/aishwarya.json`.

- Project rules and commands: `CLAUDE.md`
- What is still missing: `PENDING_ITEMS.md`
- Editing content and one-edit swaps: `docs/EDITING.md`
- Booking modes: `docs/BOOKING.md`
- Sales demo walkthrough: `docs/DEMO_SCRIPT.md`

```bash
npm install
npm run dev          # http://localhost:3000
npm run check        # lint, typecheck, tests, contrast, originality, build
```
